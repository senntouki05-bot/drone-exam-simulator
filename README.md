# drone-exam-sim

二等無人航空機操縦士（回転翼マルチローター・基本）実地試験の**実技シミュレータ**。実物のプロポをUSB接続してブラウザで練習する。

- 状態: **M3完了**（M0雛形＋M1入力層＋M2飛行力学＋M3コースと幾何を実装済み・140テスト緑）／次=M4試験ロジック
- [DESIGN.md](DESIGN.md) — 全体設計（試験仕様・システム構成・マイルストーン）
- [CLAUDE-CODE-PROMPT.md](CLAUDE-CODE-PROMPT.md) — Claude Codeに貼る開発プロンプト
- [research/RESEARCH-2026-07-18.md](research/RESEARCH-2026-07-18.md) — 事前調査（一次資料の出典つき）

## 始め方

```bash
cd ~/dev/drone-exam-sim && npm install && npm run dev   # ブラウザで飛ばす（Chrome推奨）
npm test                                                # 140テスト
# 開発の続き: claude を起動し CLAUDE-CODE-PROMPT.md を貼って「M4から」と指示
```

## ハードウェア前提

- EdgeTX系プロポ（RadioMaster等）ならUSBケーブル1本で接続可。
- **DJI純正送信機は非対応**（HIDとして認識されないため）。

## M1実機受入手順（人間の受入項目）

M1入力層の自動テスト（`npm test`・Gamepadモック注入）は緑だが、実機での確認は人間の受入項目。以下を順に確認する。

1. Chrome(macOS)で `npm run dev` → 表示URLを開く（入力デバッグ画面は `?input=debug` を付与）
2. プロポをUSB接続（EdgeTX機は接続時のダイアログで「USB Joystick (HID)」を選択）。またはゲームパッド（Xbox等）を接続。DJI純正送信機は非対応
3. 画面右上パネルの案内どおり、スイッチを操作するか任意のボタンを押す → 機器名が表示されること
4. 「キャリブレーション開始」→ ウィザードの指示で4軸＋宣言ボタンを登録 → 完了
5. `?input=debug` で各生軸の値が動き、正規化4軸が期待方向（スロットル上=+1等）に振れること
6. ページ再読込→スイッチ/ボタンで再認識 → 保存済み設定が自動復元されること（再ウィザード不要）
7. モード1/モード2切替でスロットルとエレベーターの割当が入れ替わること
8. 未接続時はキーボード（W/S=スロットル・A/D=ラダー・↑↓=エレベーター・←→=エルロン・Space=宣言）で操縦できること
