# drone-exam-sim

二等無人航空機操縦士（回転翼航空機・マルチローター・基本）実地試験の**実技シミュレータ**。実物のプロポをUSB接続（Gamepad API）し、ブラウザ上で実技3課目を試験と同じコース寸法・減点基準で練習する。バックエンドなしの完全静的Webアプリ（Chrome推奨）。

- 状態: **M5完了**（M0〜M5全実装。テスト件数は `npm test` 参照）
- デモ（公開中）: **https://drone-exam-sim.pages.dev/** — プロポ未接続でもキーボードで操作可（画面右上・下部の操作案内参照）
- 仕様の正本: [CLAUDE-CODE-PROMPT.md](CLAUDE-CODE-PROMPT.md) ／ 全体設計: [DESIGN.md](DESIGN.md) ／ 事前調査（一次資料の出典つき）: [research/RESEARCH-2026-07-18.md](research/RESEARCH-2026-07-18.md)

## 概要（何ができるか）

| 機能 | 内容 |
|---|---|
| 実技3課目 | 4-1 スクエア飛行（位置安定ON・高度3.5m・制限8分・13m×5m）／4-2 8の字飛行（ON・1.5m・8分・直径5m円×2を連続2周）／4-3 異常事態における飛行（**OFF=ATTI**・3.5m・6分・13m直線往復→緊急着陸） |
| 実プロポ接続 | USBジョイスティックとして認識されるプロポをGamepad APIで接続。キャリブレーションウィザード・モード1/2切替・キーボードフォールバック |
| 細則準拠の採点 | 減点式（持ち点100・70点以上で合格）。区画逸脱・危険速度・指示違反などを自動判定し、終了後に減点内訳＋軌跡上面図のレポートを表示 |
| 挙動再現 | GPSモード（位置ホールド）／ATTIモード（風で流れる・当て舵が必要）の制御則差＋風モデル（定常＋突風＋乱流）＋機体プロファイル3種 |
| 練習モード | 課目単体・区画/軌跡表示・風/機体/カメラの変更・ミニマップ・リプレイ（JSONエクスポート/インポート） |
| 試験モード | 3課目通し（4-1→4-2→4-3）・区画非表示・試験員の音声指示（字幕併記）・スコア履歴 |

⚠️ ATTIモード指定は4-3のみ（「二等の実技は全部ATTI」という巷の解説は細則と食い違う。一次資料が正）。

## 使い方

### キーボード操作（プロポ未接続時のフォールバック）

配置はモード2相当（W/S/A/D=左スティック・矢印=右スティック）。

| キー | 機能 |
|---|---|
| W / S | スロットル（上昇/下降） |
| A / D | ラダー（左右旋回） |
| ↑ / ↓ | エレベーター（前進/後退） |
| ← / → | エルロン（左/右移動） |
| **Space** | **安全確認の宣言**（離陸前・着陸前。実試験の「安全確認よし」の呼唱の代替。宣言しなくても進行はブロックされないが SAFETY −5） |
| M | GPS ⇔ ATTI 切替（4-3はATTI固定） |
| V | 風プリセット切替（屋内無風 → 屋外弱風2m/s → 屋外強風3.5m/s＋突風） |
| C | 機体切替（phantom4-like → soten-like → trainer） |
| 1 / 2 / 3 | 課目切替（4-1 / 4-2 / 4-3） |
| Z | 区画帯（減点/不合格）の表示切替（練習モードのみ） |
| H | 最小HUD切替（課目・時間・字幕のみ表示） |
| R | 位置リセット（**受験中は課目中止**・リプレイ再生中は再生停止） |

受験中はR（中止）以外の切替キーは無効（受験前に設定を済ませる）。

### プロポ接続とキャリブレーション

1. プロポをUSB接続（EdgeTX機は接続時ダイアログで「USB Joystick (HID)」を選択）
2. **スイッチを操作するか、いずれかのボタンを押す**（Chromeはボタン押下があるまでデバイスを露出しないことがある。スティック操作だけでは認識されない場合がある）
3. 画面のパネルに機器名が出たら「キャリブレーション開始」→ ウィザードの指示どおり4軸（スロットル/ラダー/エレベーター/エルロン）＋宣言ボタンを登録
4. 設定は機器IDごとにlocalStorageへ保存され、再読込後も自動復元される。モード1/2はいつでも切替可
5. 認識されないときは: タブにフォーカスがあるか／ケーブルがデータ通信対応か／プロポがジョイスティックモードか を確認。`?input=debug` をURLに付けると生軸・正規化値のデバッグ画面が出る

### 練習モード（課目単体）

- 課目を選んで単体練習。減点/不合格区画の半透明帯・軌跡・ミニマップを表示できる
- 風（プリセット/スライダー）・機体（3種）・カメラ（操縦者定点/俯瞰/追従）を変更可能
- リプレイ: 飛行を20Hzで記録し、JSONエクスポート/インポートして見返せる

### 試験モード（3課目通し）

- 4-1→4-2→4-3 の順で通し受験。**持ち点100点は3課目を通じて単一**（課目ごとにリセットしない）。各課目終了時に70点以上を維持していれば合格、下回った時点で不合格
- 課目間は機体をHへ再配置（スコアは持ち越し）。区画帯は非表示（実試験どおり目測で飛ぶ）
- 試験員指示はSpeechSynthesisのローカル音声（macOSならKyoko等）＋字幕。ローカル音声が無い環境では字幕のみに自動フォールバック
- 離陸前・着陸前に **Space（または割当ボタン）で安全確認を宣言**するのを忘れずに（忘れると−5）
- 終了後レポート: 合否・最終点・所要時間・減点内訳の時系列・上面図（軌跡＋減点位置）。スコア履歴はlocalStorageに保存

## 対応プロポ

一次情報（メーカー資料・開発者向けマニュアル）に基づく対応表。**本シムでの実機検証は未実施**のため、手元の機体では下記「M1実機受入手順」で確認すること。出典は [research/RESEARCH-2026-07-18.md](research/RESEARCH-2026-07-18.md) §B。

| プロポ | 接続方法 | 備考 |
|---|---|---|
| EdgeTX系（RadioMaster / Jumper / BETAFPV 等） | **USBケーブル1本**（USBジョイスティックモード） | HID化して8軸＋24ボタンを露出（EdgeTX公式マニュアル記載） |
| Flysky FS-i6S | USB直結 | 取扱説明書にHID認識の記載あり・実機動作は要確認 |
| FrSky系 | XSR-SIM無線ドングル、またはトレーナーポート＋8in1シミュレータケーブル | 要確認（機種により差がある） |
| Futaba / JR 等 | **トレーナーポート＋8in1シミュレータケーブル**（PPM→USB HID変換） | 要確認 |
| 汎用ゲームパッド（Xbox等） | USB / Bluetooth | 動作可。ただしスティックの節度・ストロークが実プロポと異なり**実技の練習感は劣る** |
| **DJI純正送信機** | **非対応** | **HIDとして列挙されない**ため接続不可。Windows専用のvJoyブリッジ（mDjiController）を要する＝ブラウザでは実質不可。例外としてDJI FPVコントローラー2はUSB-CでHID動作の報告あり |

- Gamepad APIはsecure context（HTTPS または localhost）必須。推奨ブラウザはChrome（SafariはGameController framework依存で汎用USB HIDジョイスティックが露出しない可能性＋rAF 60Hz制限）

### M1実機受入手順（人間の受入項目）

入力層の自動テスト（`npm test`・Gamepadモック注入）は緑だが、実機での確認は人間の受入項目。以下を順に確認する。

1. Chrome(macOS)で `npm run dev` → 表示URLを開く（入力デバッグ画面は `?input=debug` を付与）
2. プロポをUSB接続（EdgeTX機は接続時のダイアログで「USB Joystick (HID)」を選択）。またはゲームパッド（Xbox等）を接続。DJI純正送信機は非対応
3. 画面のパネルの案内どおり、スイッチを操作するか任意のボタンを押す → 機器名が表示されること
4. 「キャリブレーション開始」→ ウィザードの指示で4軸＋宣言ボタンを登録 → 完了
5. `?input=debug` で各生軸の値が動き、正規化4軸が期待方向（スロットル上=+1等）に振れること
6. ページ再読込→スイッチ/ボタンで再認識 → 保存済み設定が自動復元されること（再ウィザード不要）
7. モード1/モード2切替でスロットルとエレベーターの割当が入れ替わること
8. 未接続時はキーボード（W/S=スロットル・A/D=ラダー・↑↓=エレベーター・←→=エルロン・Space=宣言）で操縦できること

## 採点の仕組み

減点式・持ち点100点・**各課目終了時に70点以上で合格**。判定は課目のフェーズ（離陸上昇/ホバリング/移動/周回/着陸…）ごとにON/OFFされる（フェーズゲーティング。例: 離陸上昇中は区画判定なし・H⇔経路間の移動中は減点区画のみ無効で不合格区画は有効）。

- 区画: 経路から水平1.5m以内=自由飛行帯／1.5m超〜2.5m=減点区画／2.5m超=不合格区画。「機体の半分以上の進入」=機体中心の境界越えで判定
- **即不合格**: 墜落・パイロン衝突（CRASH）／危険速度=概ね5m/s以上（SPEED）／不合格区画進入（ZONE_FAIL）／8の字で円中心を含まず周回（CENTER_MISS）／制限時間超過（TIMEOUT）
- **−5点**: 減点区画進入（ZONE_DEV・移動レグごとの初回は警告後概ね2秒以内の復帰でセーフ）／指示と異なる飛行（WRONG_OP: 高度・機首方向・周回方向・指示前の移動）／着陸不良（LAND_BAD）／安全確認の宣言忘れ（SAFETY）
- **−1点**: ふらつき（WOBBLE）／不円滑（ROUGH）／一時的な機首方向不一致（HEADING）。**突風起因のふらつきは速やかに修正すれば減点しない**（突風イベント直後の猶予窓）
- 閾値・FSM既定値は [data/deductions.json](data/deductions.json) で調整可能。**細則に明文がない値は `_note` に「仮置き」と明記**（要現地調整）
- 実試験の「監視不足」（実試験では−5）「操縦装置を両手で保持しない」（実試験では即不合格）は視線・手の検出が不可能なため**採点対象外**（UIにも明記。実試験ではここも見られることに注意）

> **免責**: 本シムは公開資料に基づく再現であり、**採点・挙動が実試験と同一であることは保証しない**。数値の正本は国交省航空局「二等無人航空機操縦士実地試験実施細則 回転翼航空機（マルチローター）」（https://www.mlit.go.jp/koku/content/001971375.pdf ・令和7年12月5日改正版）。機体の飛行パラメータは実機値が非公開のためチューニング前提の近似値（`data/machines/*.json` の `_note` 参照）。

### 技術スタック

- Vite + TypeScript + Three.js + Vitest。物理エンジン・UIフレームワークは不使用（自前積分・素のDOM）
- バックエンドなし・完全静的・外部CDN読み込みなし（全アセットをバンドル）。UIは日本語・対象ブラウザはChrome(macOS)

### アーキテクチャ

`core/`（固定Δtループ）→ `input/`（Gamepad・キャリブレーション・キーボード）→ `sim/`（6DOF自前積分＋カスケード制御＋風）→ `exam/`（課目FSM・採点・試験員指示）→ `render/`（Three.jsシーン・機体・コース）＋ `ui/`（HUD・レポート・設定）の層構成。**`exam/` はヘッドレスな純粋モジュール**（DOM・WebGL・Audio系APIを一切importせず、音声・乱数・タイミングはコンストラクタ注入）で、公開APIは `session.step(tSim, {p, v, q, mode}, events)` の1本。このため採点ロジックは物理を通さず合成軌道の注入だけでVitestにより機械検証できる（理想軌道→減点0・変形軌道→期待どおりの減点コード）。

座標系はワールド=three.js（y上・受験者はz+側）／コース=原点A・x右・z奥で、変換は `src/exam/Course.ts` の `courseToWorld`/`worldToCourse` に集約。
